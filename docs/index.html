Engineered for the Mac.

Every detail follows Apple Human Interface Guidelines and modern Swift 6 architecture.

ScreenCaptureKit Self-Exclusion

Configured with sharingType = .none. macOS WindowServer automatically omits Pipsey's companion bar from recorded video frames, eliminating UI occlusion and preventing self-capture contamination.

Two-Model Grounded Vision

Separates visual perception from conversational reasoning. A small remote VLM strictly observes timestamped UI transitions, while an independent LLM produces natural explanations and production code.

Liquid Glass Settings Window

Native macOS Tahoe .fullSizeContentView preferences window with NavigationSplitView. Manage BYOK API keys in Keychain (OpenAI, Azure, Anthropic) with live connectivity tests.

Searchable Interaction Library (⌘H)

Every completed explanation is saved locally to session_history.json. Search previous analyses, copy generated code snippets, and export standalone Markdown reports with one click.

Active App Context Sensing

Automatically senses the frontmost active application (Figma, Xcode, VS Code, Chrome, Linear) and tailors the code synthesis to your target stack (SwiftUI, React Framer Motion, CSS tokens).

Privacy & Security Fail-Closed

Zero background recording. Captures frames strictly upon explicit user hotkey invocation. Includes an explicit external upload consent gate and purges temporary disk files immediately after sampling.
